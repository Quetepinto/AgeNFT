## Vídeo 2 — [Si quieres lanzar un SaaS, te queda menos tiempo del que crees](https://www.youtube.com/watch?v=Tnk1Y61I3F8) (~9 min)

### Resumen

| Tema | Qué dice |
|------|----------|
| **Cambio de juego** | La IA eliminó la barrera “saber construir”. Cualquiera lanza productos en días. |
| **Nuevo cuello de botella** | **Distribuir** y **validar** — no programar. Product Hunt saturado, Reddit banea promo, 50 founders lanzan lo mismo cada martes. |
| **Trayectoria del autor** | Failping (uptime) → manual, Product Hunt fácil, Reddit funcionaba. SiteDots → más IA, lanzar ya más duro. ConvoHunter → Cursor/Claude, aún más difícil aunque tuviera más audiencia. |
| **No-devs entrando** | Marketers y business lanzan SAS “sólidos” con vibe coding — traen **clientes y ventas**, no código perfecto. |
| **Error de devs** | Perfeccionar infra para 10k usuarios que no existen; postergar el lanzamiento. |
| **Nueva ventaja** | Quién entiende **para quién** construye — no quién programa mejor. |
| **Urgencia** | Ventana de oportunidad se cierra; intentos limitados en la vida (15 teóricos, menos en práctica); **ahora** mejor que dentro de un año. |
| **Productos citados** | Failping, SiteDots, [ConvoHunter](https://convohunter.com/), FounderForge (waitlist). |

### Citas útiles

> “Cuando construir ya no es barrera, es solo la entrada a donde están los problemas de verdad.”

> “El juego lo decide quién entiende mejor para quién está construyendo.”

> “No te quedan meses, te quedan **intentos**.”

## Lecciones para ageNFT (este vídeo)

| Lección | Acción concreta |
|---------|-----------------|
| **No esperar al producto perfecto** | MVP Unit-Mainnet ya en mainnet — seguir cableando, no re-arquitectar 6 meses |
| **Distribución > features** | Gespenster, exposiciones, demo transfer, Base/OpenSea — no solo GitHub |
| **Nicho claro** | “Agente coleccionable que posees” — no “otro chat IA” |
| **Ventana** | ageNFT + agentes onchain + x402 es **ahora**; documentar y lanzar visible |
| **ConvoHunter** | Scout social para **encontrar** nicho donde el agente especializado tiene valor — no spam Reddit |
| **Audiencia** | Newsletter/comunidad del proyecto (owner + Gespenster) antes de escalar |
| **Código “sucio” OK** | Runtime mínimo que funciona > arquitectura para millones |

### Lo que NO aplica tal cual

- ageNFT no es SAS mensual clásico — es **activo NFT** (modelo distinto).  
- “Lanzar ya” no significa prometer autofinanciación — honestidad del [`self-funding.md`](self-funding.md).
